为了方便连接，需要配置~/.ssh/config保证私钥文件可以被识别到。
**在本地**准备好私钥文件，编辑**本地的**配置文件。
```bash
vim ~/.ssh/config
```
加入如下内容，内容细节视具体情况而定。
```plaintext
Host 112.126.87.83-admin_me
    HostName 112.126.87.83
    User adminMe
    Port 2222
    IdentityFile ~/.ssh/comardom.top.taskapsule.xyz.pem

Host 112.126.87.83-normal_me
    HostName 112.126.87.83
    User normalMe
    Port 2222
    IdentityFile ~/.ssh/comardom.top.taskapsule.xyz.pem
    
Host 47.93.40.173-admin_me
    HostName 47.93.40.173
    User adminMe
    Port 2222
    IdentityFile ~/.ssh/comardom.top.taskapsule.xyz.pem

Host 47.93.40.173-normal_me
    HostName 47.93.40.173
    User normalMe
    Port 2222
    IdentityFile ~/.ssh/comardom.top.taskapsule.xyz.pem
```
设置文件权限。
```bash
chmod 600 ~/.ssh/config
```
此时可以进行ssh测试，以确保config可用。
```bash
ssh 112.126.87.83-admin_me
```
此时可以进入Dolphin，在地址栏中键入此地址进行测试。
```plaintext
sftp://112.126.87.83-admin_me/var/www/
```
如果一切顺利，就可以在你喜欢的地方创建一个快捷方式以便于快速进入远端服务器管理文件。
```bash
vim 112.126.87.83-adminMe.desktop
```
文件内容如下。
```bash
[Desktop Entry]
Icon=folder-remote
Name=sftp://112.126.87.83-adminMe/var/www/
Type=Link
URL[$e]=sftp://112.126.87.83-adminMe/var/www/
```
# 使用Dolphin管理文件
Dolphin是KDE Plasma桌面环境的默认文件管理器，对远端文件管理有直接支持。GNOME默认的Nautilus、Xfce的Thunar等文件管理器，均支持相似的流程，此处以Dolphin作为例子。
使用方法如下。
首先，Dolphin采用kio-sftp进行密钥匹配的检测，而如果根据[[登录到服务器（Debian）]]进行配置，服务器并没有留出密码登录的机会。
如果你愿意使用密码登录（没有禁用密码登录），可以按照下面这个流程执行。
1. 在侧边栏中找到“远程位置”栏目。
2. 点击“网络”文件夹。
3. 找到地址栏附近的“添加网络文件夹”并点击。
4. 此时弹出窗口“网络文件夹向导-KDE网络向导”，内部标注“添加网络文件夹”。
5. 点击“SSH（安全Shell）”，并点击下一步。
6. 此时出现“网络文件夹信息”的内容，包括名称、用户、服务器、端口、协议、文件夹、编码等。
7. 名称填写自己喜欢的名字，最好醒目一些，比如直接写“normalMe登录的112.126.87.83的www文件夹”。
8. 用户填写你想要登录的==服务器账户==，比如normalMe。
9. 服务器填写你服务器的IPv4。
10. 端口填写SSH的登录端口。
11. 协议选择sftp。
12. 文件夹推荐“/var/www/”，这个文件是一般情况下的网页文件所在地。当然也可以写其他喜欢的文件夹，结尾记得写斜杠。
13. 编码一般直接选择UTF-8，很少有其他需求。
14. 如果有复选框标注“创建次远程文件夹的图标”，可以勾选上，使得==本地机器==上可以看到一个常驻的远端文件夹。
15. 点击“保存并连接”。
16. 输入密码，连接成功。
17. 或者使用“sftp://adminMe@112.126.87.83:2222/var/www/”地址进行连接，效果一致。
